# Glosario fijo

Usa siempre el término de la derecha. Si un término no está aquí, elige el habitual en los cursos de programación en español y mantenlo igual en todo el lote.

| Inglés | Español |
|---|---|
| array / subarray | arreglo / subarreglo |
| string / substring | cadena / subcadena |
| subsequence | subsecuencia |
| query | consulta |
| integer | entero |
| test case | caso de prueba |
| input / output (sustantivo) | entrada / salida |
| print / output (verbo) | imprime |
| space-separated | separados por espacios |
| graph / tree | grafo / árbol |
| vertex / node | vértice / nodo |
| edge | arista |
| path / cycle | camino / ciclo |
| road | carretera (nunca "camino", que es "path") |
| sequence | secuencia |
| pile / heap (de piedras, cartas) | montón (no "pila", que es "stack") |
| sample / test (en las notas: "In the first sample") | ejemplo ("En el primer ejemplo") |
| lowercase / uppercase English letters | letras minúsculas / mayúsculas del alfabeto inglés |
| in any case (upper or lower) | en mayúscula o en minúscula |
| to write a contest | participar en un concurso |
| connected component | componente conexa |
| grid / cell | cuadrícula / celda |
| row / column | fila / columna |
| segment / interval / range | segmento / intervalo / rango |
| prefix / suffix | prefijo / sufijo |
| permutation | permutación |
| even / odd | par / impar |
| pair | par (o "pareja" si se confunde con par e impar) |
| distinct | distintos |
| non-decreasing / non-increasing | no decreciente / no creciente |
| lexicographically smallest | lexicográficamente menor |
| modulo | módulo |
| greatest common divisor | máximo común divisor |
| stack / queue | pila / cola |
| It is guaranteed that | Se garantiza que |
| If there are multiple answers, print any | Si hay varias respuestas, imprime cualquiera |
